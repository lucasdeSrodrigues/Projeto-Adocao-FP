Adoção+ – Sistema de Gestão de Centro de Adoção de Animais

#  Descrição
O Adoção+ é um sistema em Python desenvolvido para auxiliar centros de adoção de animais a organizar informações sobre cães, gatos e outros pets.  
Ele permite controlar dados dos animais, registrar cuidados e atividades, acompanhar saúde e sugerir perfis de adoção de forma prática e eficiente.


#  Funcionalidades
- CRUD de Animais: adicionar, visualizar, editar e excluir animais.
- Cadastro de Cuidados e Atividades: registrar vacinas, banhos, consultas veterinárias e treinos.
- Contagem regressiva e alertas: cálculo de dias restantes para próximas tarefas importantes.
- Armazenamento em CSV: histórico completo salvo em arquivos `.csv`.
- Sugestões personalizadas: recomendações de cuidados e perfis de adotantes com base em idade, espécie, comportamento e saúde.
- Funcionalidade extra: destaque do animal mais apto à adoção.


#  Como usar
1. Clone ou baixe este repositório.
2. Certifique-se de ter Python 3.x instalado.
3. No terminal, execute:
   git clone (link do repositório)
4. Acesse a pasta do projeto (Projeto-Adocao-FP)



# Use o menu interativo para navegar:

1. Adicionar animal
2. Visualizar animais
3. Editar animal
4. Excluir animal
5. Gerenciar cuidados e atividades
6. Sugestões personalizadas
7. Animal destaque do abrigo
   
0\. Sair

   
# Restrições:

- O sistema roda apenas em linha de comando.
- Não utiliza bibliotecas externas além de:
    - os (para limpar tela)
    - datetime (para cálculos de datas)
    - random (para funcionalidades extras)
    - csv (para salvar e carregar dados)
- Os dados são salvos em arquivos locais (.csv), sem banco de dados.
